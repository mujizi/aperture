标题：一个OPC做了个Codex插件

正文：
最近我越来越强烈地感觉到：

大模型的输出带宽在快速增长，但人的注意力带宽没有变。

Codex 可以同时完成多个任务，可任务结束后，我仍然要逐个打开对话，重新判断：结果是什么？有没有需要我决定的事？哪里被阻塞了？证据在哪里？

所以我做了 Aperture——一个放在人类输入带宽与模型输出带宽之间的注意力中间层。

它不是简单地把答案变短，而是把完成的 Codex 任务重新组织成：

✓ 最终结果
✓ 真正需要人决定的事项
✓ 阻塞与未解决问题
✓ 必须保留的证据和上下文

任务完成后，它会自动出现在工作区旁边；看完可以收成一个可拖动的小球，也能前后切换已经完成的任务。

我最在意的一点是：焦点可以改变，但事实不能被摘要掉。

会话捕获、历史和渲染都留在 Mac 本地。注意力分析时，只把清理后的问题和最终答案发给配置的 OpenRouter 模型，不发送原始工具调用与工具输出。

目前还是早期预览版，支持 Apple Silicon / macOS 13+，项目已经开源。

GitHub 搜索：mujizi/aperture
