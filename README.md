<h1 align="center">Aperture</h1>

<p align="center">The attention layer between human input bandwidth and model output bandwidth.</p>

<p align="center"><a href="README.en.md"><strong>EN</strong></a> · <a href="README.cn.md"><strong>CN</strong></a></p>

Aperture is not a summarizer. It remaps a completed Codex response into the bandwidth a human can absorb now: what should be seen first, what must remain visible, and what can recede into context.

The attention pass is independent from Codex. Choose models from different upstream providers through OpenRouter—including inexpensive, fast models—and turn monitoring on or off at any time.

Choose **EN** or **CN** above for installation, requirements, operation, settings, capabilities, and design philosophy.
